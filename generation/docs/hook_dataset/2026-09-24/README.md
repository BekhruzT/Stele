# YouTube hook corpus and six-topic experiment

45 editorially selected opening passages from five channels, drawn from 234
cached public transcripts: SciShow (23), SciShow Space (10), Bizarre Beasts (7),
Crash Course (3), and Journey to the Microcosmos (2).

These teach useful constructions, not necessarily ideal literal first sentences.
Every record includes the exact contiguous quote, literal first sentence, skipped
preamble, character offsets, source URLs, hashes, rationale and transfer limits.
Some passages are long or playful; distill the working idea into our calm opening.

It foregrounds the latest automatic selections, with all candidates, earlier runs,
approved references and the complete searchable corpus underneath. Rejected pools
are explicitly shown without a selected hook. latest-evaluation.json identifies
the current run; manual proposals are historical comparison material only.

The latest recorded six-case evaluation used reference-editorial-v5.9-discovery.
The current checkout uses reference-editorial-v6.2-first-promise: a shorter writer goal
with all 45 quoted openings rendered as plain text in the writer's system message.
One chooser call checks whether each draft keeps the main story in focus, creates interest
in that focus, and is supported by the research. Lore entry points default to GPT-6 Astra with high
reasoning, with explicit overrides still supported. Hook evaluations bypass all
approved locks and do not supply hand-written topic answers to either hook writer
or listener. Production retains existing user approvals unless fresh_hook is set.

The latest comparison changes both the writer/selection prompts and reasoning
effort. It is not an isolated measurement of either change. See the review report
for actual outputs; model review passes do not prove audience appeal. Full
transcript bodies are not regenerated by these hook-only evaluations.

## Acquisition and scope

The original caption service was healthy but could not extract YouTube player
responses. Six additional videos from six channels also failed. Its generic 404
does not establish that captions are absent; the precise cause remains unknown.
Diagnostics are saved in artifacts/youtube-hooks-20260924/diagnostics/.

Nerdfighteria Wiki provided a working alternative. Its community transcripts
were checked against cached archive text, not independently against audio.
The corpus is mostly science, not a representative sample of the original
sleep-history channels. Six older reference-channel transcripts remain cached
separately; two were also fetched fresh. available-openings.json is that earlier
six-source inventory, not the selected prompt corpus, which is hooks.json.

A suspicious pair shared an opening despite unrelated titles; neither was
selected. Greeting-only, recap-heavy, footage-dependent and weak generic openings
were generally excluded. Views were not used as causal evidence of hook quality.

## Prompt integration and experiment

core/hook_examples.py loads all 45 into the brief, writer, selector, repair and
repaired-hook check. No nearest-example retrieval. Each run saves a full corpus
snapshot and hash. Examples are constructions, not factual research or commands.

First run: 20260924-youtube45 (v4.0). Second: 20260924-youtube45-calibrated (v4.1).
The second restores explicit user rejection criteria after the first run's
failures. Both use GPT-6 Astra and the same six existing research bundles. Fresh
calls exclude literal approved answers; normal production protects the registry.

The first selector passed all six despite clear editorial failures. Model pass
labels are shown separately from editorial assessments. This is a combined
prompt-and-examples comparison, not a controlled causal test. Existing full
transcript bodies were not regenerated or replaced.
